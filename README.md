# FamiliadeAMuchis · Escapadas

PWA para el móvil para descubrir Tenerife en grupo: sitios por municipio,
marcas (🔖 Quiero ir / ✅ Fuimos / ✖️ No), ⭐ y notas. Funciona sin conexión.
HTML, CSS y JS puro, en GitHub Pages.

- Reglas del proyecto: [CLAUDE.md](CLAUDE.md) · Diario: [PROGRESO.md](PROGRESO.md)
- Catálogo de sitios (público): [data/sitios.json](data/sitios.json)

## Activar GitHub Pages (desde el móvil)
1. Abre el repo en github.com (en el navegador, no en la app de GitHub) y
   toca **Settings** (si no aparece, pon el navegador en «Versión para ordenador»).
2. En el menú, **Pages**.
3. En «Build and deployment» → Source: **Deploy from a branch**.
4. Branch: **main** y carpeta **/ (root)** → **Save**.
5. Espera 1-2 minutos y abre
   https://paniaguadediego-bit.github.io/FamiliadeAMuchis.Escapadas/
6. Instálala: Chrome → menú ⋮ → «Instalar aplicación» (iPhone: Compartir →
   «Añadir a pantalla de inicio»).
